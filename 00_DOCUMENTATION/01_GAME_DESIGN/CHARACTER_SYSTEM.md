# Character System

## Launch Roster

Exactly five characters at launch.

| Character | Role | Personality |
|---|---|---|
| Capybara | Default/free | Chill, goofy, relaxed |
| Cat | Collectible cosmetic | Playful, slightly sassy |
| Dog | Collectible cosmetic | Energetic |
| Penguin | Collectible cosmetic | Cute/comedic |
| Panda | Collectible cosmetic | Calm/sleepy |

## Locked Visual Representation

The standard character representation is **face-only / head-and-face iconography**.

For gameplay, shop, collection, selection and other compact UI contexts, show the animal's cute face rather than a full body.

Full-body artwork is allowed only as separate promotional/showcase artwork where useful. It does not replace the core face-only character system.

## Ultra-Cute Standard

Every launch character must be designed to be **ultra-cute**.

Required visual qualities:

- large expressive eyes
- rounded head
- soft cheeks
- small cute mouth
- friendly expression
- soft proportions
- clean silhouette
- immediately readable at small sizes

The characters should feel irresistibly cute without becoming generic emoji.

Avoid:

- realistic anatomy
- sharp or intimidating features
- creepy eyes
- excessive detail
- cluttered accessories
- aggressive expressions
- inconsistent art styles

## Individual Face Direction

### Capybara
Round, calm, warm, lovable face.

### Cat
Rounded ears, soft cheeks, playful/sassy expression.

### Dog
Rounded/floppy ears, happy energetic expression.

### Penguin
Round head, tiny beak, soft comedic expression.

### Panda
Round ears, chubby cheeks, calm sleepy expression.

## Shared Character Language

All five characters must share:

- consistent eye style
- consistent facial construction
- consistent proportions
- consistent rendering
- consistent softness
- consistent shading language
- consistent color treatment

They must look like one collectible character family.

## Character Reactions

Each character needs face-based versions of:

- idle
- selected
- placement
- correct
- removal
- wrong placement
- completion
- perfect completion
- unlock
- Golden Challenge
- reward

## Rules

- Characters never change puzzle rules.
- Characters never change lives, hints, reveal behavior, score, difficulty, or reward probability.
- No character has a gameplay stat.
- Capybara is available by default.
- Future animals may be added post-launch without changing these principles.

## Rarity

Rarity is a collection/economy classification only.

Starting categories:

- Common: 500–1,000 coins
- Rare: 1,500–2,500 coins
- Epic: 3,000–5,000 coins

Final assignments are configurable after economy simulation.

## Golden Treats

Golden Treats are a visual collectible variant tied to the active character in Golden Challenge results. They are not spendable currency and do not grant gameplay power.

## Future Expansion

New animals, skins, themes, and presentation variants may be introduced post-launch. Any future gameplay-affecting mechanic requires a new product-design approval and must not silently enter the launch rules.
