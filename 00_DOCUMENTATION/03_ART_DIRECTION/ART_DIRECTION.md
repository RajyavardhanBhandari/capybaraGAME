# Art Direction

## Identity

Cute, warm, polished, modern animal puzzle game.

Capybara is the visual anchor.

## Character language

Characters should be:
- immediately readable at small sizes
- expressive
- friendly
- visually distinct
- animation-friendly
- original

Launch roster:
Capybara, Cat, Dog, Penguin, Panda.

Personality:
Capybara = chill/goofy/relaxed.
Cat = playful/slightly sassy.
Dog = energetic.
Penguin = cute/comedic.
Panda = calm/sleepy.

## Puzzle board

Priorities:
- exceptional readability
- clean region boundaries
- clear selected state
- obvious valid/invalid feedback
- minimal visual noise
- consistent cell geometry

Do not rely on color alone for state communication.

## UI

Use a soft, friendly visual system with strong hierarchy.
Buttons must be large enough for comfortable mobile touch.
Economy values must remain legible.
Competitive results must be visually clear without aggressive gamification.

## Animation

Required states:
- idle
- selected
- placed
- removed
- wrong
- success
- perfect success
- unlock
- reward

Animations must support the puzzle rather than distract from it.

## Originality

Do not reproduce third-party character art, UI layouts, audio, branding, distinctive assets, or code. Inspiration is limited to broad product patterns such as simplicity, short sessions, collection, feedback, and optional monetization.

## Asset pipeline

All production assets should be source-controlled or linked to an explicit asset repository/version.
Final Unity import settings must be documented.
