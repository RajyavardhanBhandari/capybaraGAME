# Art Direction

## Identity

Cute, warm, polished, modern animal puzzle game.

Capybara is the visual anchor.

## Locked Character Icon Direction

All five launch animals must use a **face-first / face-only character icon** as their standard in-game representation.

The default gameplay/shop/collection icon is:

**head + face only**

Do not use full-body animal art as the default character representation.

Full-body artwork may exist separately for marketing, promotional illustrations, special showcases, or other approved presentation contexts, but the core character icon remains face-only.

## Ultra-Cute Requirement

The launch animals must be **ultra-cute and emotionally appealing**.

The intended reaction is:

> “I want to tap this little face.”

Prioritize:

- large expressive eyes
- soft rounded shapes
- chubby cheeks
- small cute mouths
- friendly expressions
- soft proportions
- rounded silhouettes
- simple readable facial features
- strong but adorable emotional reactions

Avoid:

- aggressive expressions
- sharp/angular faces
- realistic animal anatomy
- creepy or overly realistic eyes
- excessive facial detail
- generic emoji-like treatment
- visually noisy accessories
- intimidating expressions

## Character Silhouette

Each animal must be identifiable from its head/face silhouette, even at small mobile sizes.

### Capybara
Round, calm, warm, extremely lovable face.

### Cat
Rounded ears, soft cheeks, playful expression.

### Dog
Rounded/floppy ears, happy expressive face.

### Penguin
Rounded head, tiny beak, soft and adorable expression.

### Panda
Round ears, chubby cheeks, gentle calm/sleepy expression.

## Shared Visual Universe

All five characters must clearly feel like they belong to the same game.

Maintain consistency in:

- eye construction
- facial proportions
- head proportions
- line treatment
- shading
- rendering
- softness
- color treatment
- expression language

They should feel like one coherent character family, not five unrelated illustrations.

## Gameplay Expressions

The face-only characters must support:

- idle
- selected
- happy
- correct
- confused
- mistake
- surprised
- celebration
- perfect
- sleepy/calm
- unlock/reveal

## Launch Roster

- Capybara — chill, goofy, relaxed
- Cat — playful, slightly sassy
- Dog — energetic
- Penguin — cute/comedic
- Panda — calm/sleepy

Capybara remains the flagship mascot.

## Puzzle Board

Priorities:

- exceptional readability
- clean region boundaries
- clear selected state
- obvious valid/invalid feedback
- minimal visual noise
- consistent cell geometry

Do not rely on color alone for state communication.

## UI

Use a soft, friendly visual system with strong hierarchy.

Buttons must be large enough for comfortable mobile touch.

Economy values must remain legible.

Competitive results must be visually clear without aggressive gamification.

## Animation

Required states:

- idle
- selected
- placed
- removed
- wrong
- success
- perfect success
- unlock
- reward

Animations must support the puzzle rather than distract from it.

## Originality

Do not reproduce third-party character art, UI layouts, audio, branding, distinctive assets, or code. Inspiration is limited to broad product patterns such as simplicity, short sessions, collection, feedback, and optional monetization.

## Asset Pipeline

All production assets should be source-controlled or linked to an explicit asset repository/version.

Final Unity import settings must be documented.
